# Trained model — training-time outputs

This directory holds the diagnostic artifacts emitted during training of
the Conan-ML all-angle contact angle model. They're kept here for
reproducibility and historical reference; none of them are loaded at
runtime.

## Contents

- `history.pkl`, `trainHistoryDict.pkl` — per-epoch loss / MAE / MSE
  history pickles produced by `train_model.py` and `train_continue.py`.
- `training_history.png`, `training_history_all.png` — training / validation
  loss curves. The `_all` variant combines multiple training runs
  (generated by `parse_output.py`, see `training_files/`).
- `test_data.png`, `test_set_spread.png` — evaluation plots produced
  during training (predicted vs. ground-truth angle on the held-out set,
  and the spread of the test set).
- `outputted_data.txt` — raw stdout capture from a training run
  (used by `parse_output.py` to build `training_history_all.png`).
- `modelsummary.txt` — Keras `model.summary()` output for the final
  architecture.

## Where the runtime model lives

The TensorFlow SavedModel the app actually loads (the `.pb` files and
`variables/` directory) is **not** in this directory. It lives at:

    OpenDrop_OP/opendrop_ml/modules/ML_model/

Inference code imports from there. The SavedModel was placed in the
`opendrop_ml/` package so `pip install` and PyInstaller bundling pick
it up alongside the code that consumes it.
